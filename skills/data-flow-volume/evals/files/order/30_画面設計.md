# 受注管理サービス 画面設計（架空のテスト用資料）

## 画面一覧

| 画面ID | 画面名 | 利用者 |
| ---- | ---- | ---- |
| 101 | 発注入力画面 | 店舗スタッフ |
| 102 | 発注一覧画面 | 本部担当者、本部管理者 |
| 103 | 発注詳細画面 | 本部担当者 |
| 110 | 発注上限設定画面 | 本部担当者 |

## 102_発注一覧画面

| No. | 項目 | 仕様 |
| ---- | ---- | ---- |
| 1 | 絞り込み | 店舗・期間・状況で絞り込む |
| 2 | 一覧 | 絞り込みに該当する発注を表示する。既定の並びは確定日時の降順 |
| 3 | 表示件数選択 | 1ページに10件／20件から選ぶ。初期値は10件 |
| 4 | ページ送り | 前後のページへ移る |
| 5 | CSV出力ボタン | 絞り込んだ条件で発注明細をCSVに出す。本部管理者のみ押せる。期間の指定は必須 |

## 103_発注詳細画面

| No. | 項目 | 仕様 |
| ---- | ---- | ---- |
| 1 | 明細 | 発注の明細を表示する |
| 2 | 送信結果 | 仕入先への送信結果を表示する |
| 3 | いいねボタン | AIの提案数量に「いいね」を付ける。業務の要望ではなく、使い方（誰がいつ押すか）は決まっていない。本部担当者が発注ごとに1回押す想定 |
