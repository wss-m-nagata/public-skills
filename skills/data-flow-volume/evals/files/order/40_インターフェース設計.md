# 受注管理サービス インターフェース設計（架空のテスト用資料）

## GET /orders（発注一覧取得）

| 項目 | 型 | 必須 | 仕様 |
| ---- | ---- | ---- | ---- |
| page | 数値 | ○ | ページ番号。1以上 |
| perPage | 数値 | ○ | 1ページの件数。1〜200 |
| storeId | 数値 | × | 店舗ID |
| from / to | 日付 | × | 確定日の期間 |

## POST /orders/csv-jobs（CSV出力受付）

絞り込み条件を受け付け、`order.csv_job` を1件作る。生成は非同期で行い、完了後に画面からダウンロードする。
