# 受注管理サービス テーブル定義（架空のテスト用資料）

## order.order_header（発注ヘッダ）

| 列 | 型 | 説明 |
| ---- | ---- | ---- |
| order_id | BIGINT | 発注ID |
| store_id | INTEGER | 店舗ID |
| staff_id | VARCHAR(10) | 発注したスタッフ |
| ordered_at | TIMESTAMPTZ | 確定日時 |
| status | VARCHAR(20) | 状況（確定・送信済み・送信失敗） |
| memo | VARCHAR(200) | 備考 |

## order.order_detail（発注明細）

| 列 | 型 | 説明 |
| ---- | ---- | ---- |
| detail_id | BIGINT | 明細ID |
| order_id | BIGINT | 発注ID |
| item_code | VARCHAR(13) | 商品コード |
| quantity | INTEGER | 数量 |
| suggested_quantity | INTEGER | AIが提案した数量 |

## order.send_log（送信ログ）

| 列 | 型 | 説明 |
| ---- | ---- | ---- |
| log_id | BIGINT | ログID |
| order_id | BIGINT | 発注ID |
| sent_at | TIMESTAMPTZ | 送信日時 |
| result | VARCHAR(10) | 結果（成功・失敗） |
| error_message | VARCHAR(500) | 失敗時の内容 |

## order.suggest_feedback（提案の評価）

| 列 | 型 | 説明 |
| ---- | ---- | ---- |
| feedback_id | BIGINT | 評価ID |
| order_id | BIGINT | 発注ID |
| rated_by | VARCHAR(10) | 評価した本部担当者 |
| liked | BOOLEAN | いいね |

## order.csv_job（CSV出力作業）

| 列 | 型 | 説明 |
| ---- | ---- | ---- |
| job_id | BIGINT | 作業ID |
| requested_by | VARCHAR(10) | 依頼者 |
| condition | JSONB | 絞り込み条件 |
| status | VARCHAR(20) | 状況 |
| created_at | TIMESTAMPTZ | 依頼日時 |

## order.item_limit_master（発注上限マスタ）

| 列 | 型 | 説明 |
| ---- | ---- | ---- |
| item_code | VARCHAR(13) | 商品コード |
| max_quantity | INTEGER | 1回の発注の上限数 |

本部担当者が「110_発注上限設定画面」で登録する。対象の商品は約300品目。
