# インストール手順（{{サービス名}}）

Pythonサービスの依存関係を準備する。コマンドはWindowsのPowerShellを例とする。

## 前提条件

アプリ全体の[インストール手順](../../../../docs/10_installation/インストール手順.md)に従い、Node.js・npm、Python、uvを準備する。
Pythonのバージョンはサービスの`pyproject.toml`で確認する。サービス名、環境設定と必要な権限は対象プロジェクトの決定に従う。

## 1. Node.jsの依存関係

サービスの`package.json`と`package-lock.json`にCDKやAPIテストの依存関係が定義されている場合は、サービスのディレクトリで実行する。

```powershell
npm ci
```

## 2. Pythonの依存関係

サービスの`pyproject.toml`と`uv.lock`があることを確認し、同じディレクトリで実行する。

```powershell
uv sync --locked
```

エラーなく完了し、サービスの`.venv/`に仮想環境が作られることを確認する。
実行には、例えば`uv run python --version`を使う。

## 4. 確認

型チェック用のnpmスクリプトが定義されている場合は、サービスのディレクトリで`npm run typecheck`を実行する。
CDKアプリが用意されている場合は、同じ場所で`npx cdk synth`を実行し、CloudFormationテンプレートがエラーなく生成されることを確認する。
`cdk synth`はデプロイではないが、設定や参照先によってAWSへのアクセスが必要な場合がある。
依存関係、AWS認証、環境変数やコンテナのビルドに必要な前提が揃っていない場合は実行せず、不足を記録する。
