## src/ の中の分け方

| 対象 | 役割 |
| --- | --- |
| 入口 | 要求の振り分け、接続・トランザクション、例外から応答への変換。 |
| `functions/` | APIごとの入力検証と業務判断。 |
| `repository/` | DBの読み書きとDTO。 |
| `core/` | サービス内の共通処理。 |

業務判断とDBアクセスを分け、DBに接続しない単体テストとSQLの検証を分離する。
