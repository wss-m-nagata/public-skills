# 共有インフラのリソース一覧

アプリ全体で共有するリソースと管理範囲を記載する。
リソースを追加・変更・削除するときは、定義と本資料を同じ変更で更新する。
名前は[AWSリソース命名規則](../../20_rules/AWSリソース命名規則.md)に従う。
このひな形は、採用するリソースと管理範囲が決まってから適用し、使わない節を除く。
秘密値、接続文字列や実際の認証情報は記載しない。
