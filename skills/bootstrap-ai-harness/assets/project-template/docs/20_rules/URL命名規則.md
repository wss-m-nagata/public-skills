# URL命名規則

画面URLの規則はこの資料に集約し、ほかの資料からはリンクで参照する。

## 1. 基本の形

### 規約

画面URLは、ナビゲーションのラベル・グループ・リンクに対応する`/<ラベル>/<グループ>/<リンク>`を基本とする。
階層の名前は小文字の英単語とハイフンで表す。
グループに画面が1つでも階層を省略せず、画面の増加時に既存URLを変更しないようにする。
画面が1つだけのグループは、グループと同じ名前のリンクを置く（例: `/catalog/products/products`）。
画面のないメニュー項目にはページを作らない。
**理由**: メニューの位置とURLが対応すると、画面の所属を利用者が把握しやすい。
APIのURLはサービス名を先頭に置き、画面とサービスの対応を明確にする。

メニュー階層の見せ方と操作は[画面設計規約](../../nuxt/docs/20_rules/screen-design-rules/navigation.md)に従う。
