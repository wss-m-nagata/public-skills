# bootstrap-ai-harness の設定

このファイルは、`bootstrap-ai-harness` スキルが読む設定である。
環境を作るときに、入力シート（Excel）の「ハーネスの設定」シートの値を保存したもので、入力シートが無い作業では、聞き直さずに、これを使う。
入力の正本は入力シートである。内容を変えたいときは、入力シートを直して、環境を作り直す。

記入日：<YYYY-MM-DD>

## おすすめの設定

値は、「する」「しない」「未確認」のいずれかにする。
「する」「しない」の項目は、以後、聞かない。

| 項目 | 回答 | 備考 |
| --- | --- | --- |
| 承認なしの許可・確認・禁止（`permissions`） | 未確認 | |
| 保存時の整形のフック（`formatter-hooks`） | 未確認 | |
| GitHub Actions（PRのAIレビュー、Issueの自動ラベル付け） | 未確認 | 「する」の場合は、選んだ機能を、備考に書く |

## アプリのルート

保存時の整形のフックが、対象にするディレクトリである。
リポジトリの直下にアプリがあるときは、`.` と書く。

| 項目 | 値 |
| --- | --- |
| アプリのルート | `<例：.>` |
