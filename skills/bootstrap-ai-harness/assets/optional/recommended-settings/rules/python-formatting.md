## コードの整形（Black）

- Pythonのコードの整形には、Blackを使う。設定は、既定のまま（1行は88文字まで）とする。
- Blackは、サービスの開発用の依存（`pyproject.toml`の`dependency-groups`の`dev`）に追加する。`backend/<サービス>/`で、`uv run black <ファイル>`を実行して整形する。
- AIが編集した`.py`は、フック（`.claude/hooks/formatter/black.py`）が、自動で整形する。
- サービスを追加するときは、そのサービスの開発用の依存にBlackを追加する。

**理由**: Blackは、Pythonの整形ツールとして、広く使われている標準的なツールである。  
整形をツールに任せると、書き方の違いによる差分が、レビューに混ざらない。  
Blackを、サービスの依存に入れるのは、バージョンを固定し、`uv sync`で、誰の環境にも、同じものが入るようにするためである。  
PCのPythonには、入れない。

> [AI]
> - ファイルを編集すると、フックが、自動で整形する。フックから、直せない指摘（構文エラー）が伝えられたら、コードを直す。
> - フックが動かない環境では、手で整形してから、完了を報告する。
