# 検討事項シートの記載要領

基本方針を確定し、次工程に進むために必要な事項を整理する。
「No.」「区分」「項目」「内容」の４列で一つの表にする。
区分ごとのセクションや、担当者・期限・ステータス欄は設けない。

| 区分 | 記載する内容 |
| --- | --- |
| 完了条件 | 基本方針の整理を完了とし、次工程に進むための条件。 |
| 検討事項 | 基本方針の確定までに判断・決定する必要がある事項。 |
| 課題 | 目指す姿を実現するうえで、現時点で認識している問題や懸念事項。 |
| 持ち越し事項 | 基本方針の確定には影響せず、後続工程で検討・具体化する事項。 |

基本方針の確定には、完了条件を満たし、検討事項が解消されていることが必要である。
課題と持ち越し事項は、今後の取り扱いに合意できていれば、現段階での解消は不要である。
課題や持ち越し事項が残る場合は、次工程での取り扱いに合意できていることを完了条件の行で確認する。
資料に載せるのは、方針の検討や次工程への移行に必要な事項とする。
