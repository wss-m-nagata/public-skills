# スコープシートの記載要領

どのシステム・業務・場面を対象とし、その範囲で誰が何を担当するかを示す。

- 対象・対象外・未決定の境界を示す。
  引き継ぎ支援では、開発体制、引き継ぎ単位、開発フェーズ、開発方式、前任者の状況、既存資料、実施タイミングのうち、判断に必要な観点を使う。
- 役割・責任範囲は、まず担当ごとの基本的な役割を短く示す。
  業務ごとの分担を決める必要がある場合は、業務を行、担当を列にした表にする。
  前提で分担が変わる場合は表を分ける。
  前任者が不在の表では、前任者の欄に作業を割り当てない。
- 誰が確認・承認し、誰が業務を再開できると判断するかを明確にする。
  工程の順序や受け渡しはTo-Be図に委ねる。
- 記入の手掛かりになる観点名や業務名が決まっている場合は、作成者記入欄に先に入れる。
  対象・対象外の判断と、担当ごとの分担は作成者が記入する。
- 範囲に影響する未決定事項はこのシートに示す。
  基本方針の確定までに決める事項として検討事項シートにも載る場合は、同じ項目と分かる名称にする。
