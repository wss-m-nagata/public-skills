# To-Beシートの記載要領

基本方針に合意した結果、どのような状態や業務の進め方を目指すかを示す。

- 目指す姿は、関係者が何を確認・判断できるようになるかを短い文章で書く。
  Excelでは句点で改行する。
- 目指す業務の流れは先に図で示す。
  担当が替わる場合はスイムレーンにし、引き渡す情報、確認・判断、分岐、戻り先を残す。
  工程間に余白を取り、ラベルが図形と重ならないようにする。
  確認結果を資料に戻すことが方針に含まれる場合は、誰が結果を渡し、誰が更新し、誰が使い直すかを矢印で示す。
  本流と戻りが読みづらい場合は、関連する節に循環の図を置く。
  別図に分ける場合は、本流の分岐に参照先の節番号を示し、別図にも本流へ戻る先を示す。
- 通常時と例外時で担当や進め方が変わり、比較が基本方針の判断に必要なら図を分ける。
  図で示した工程を文章や表で繰り返す前に、追加説明が判断に必要かを確認する。
- 役割の一覧はスコープシートに置く。
  To-Be図では、担当間で業務がどう進むかを示す。
  スコープに定めた完了や業務再開の判断は、To-Be図でも判断する担当と工程をそろえる。
  後続工程に持ち越した具体的な判定基準は、検討事項シートで扱う。
  対応範囲が未決定の作業は、図の注記からスコープの該当箇所を参照できるようにする。
