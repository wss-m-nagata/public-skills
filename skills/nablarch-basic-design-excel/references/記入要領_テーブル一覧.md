# 記入要領: テーブル一覧

## 資料の目的

システムが持つ全テーブルの一覧を、主管サブシステムと論理テーブル名の単位で定義する。
テーブル定義書を作成する前に、まずこの一覧でテーブルの範囲を確定させる。

## どこに何を書くか（シート『1』、見出しは7〜8行目）

| 項目名 | 記入内容 | 記入例（A1プロジェクト管理システム） |
|---|---|---|
| No. | 通し番号 | 1, 2, 3... |
| 主管サブシステム（ID／サブシステム名） | このテーブルを主に使うサブシステムのID・名称 | `A1` ／ プロジェクト管理 |
| 論理テーブル名 | テーブルの日本語名 | システムアカウント、プロジェクト、ユーザ、組織 |
| 物理テーブル名 | DB上の実テーブル名（テーブル定義書の物理テーブル名と一致） | `CLIENT`, `PROJECT` |
| 備考 | 補足事項（無ければ空欄） | - |

## 記入時のポイント

- ここに記載した論理テーブル名・物理テーブル名は、テーブル定義書のシート名・見出しと**完全一致**させる。
- 1テーブル＝1行。テーブル定義の詳細（カラム）はここには書かず、テーブル定義書側に書く。
- 複数サブシステムから共通で使われるテーブル（例：ユーザ、組織等）は、主管サブシステムを明確にしておく（どちらの設計書に定義を書くかの判断基準になる）。
