## 読み取りにくい点の補足（機械抽出では分からない構造）

機械的な抽出では次が読み取れないため、実地で確かめた内容を記す。

### 『2. レコード構成』

- 記入できるのは**9行目のレコード名（B9）だけ**。A10以降の行と、G/J/Q/S/V/AC/AH の各列はグレーアウトされている。
- 19行目「レコード構成イメージ」の下（20行目以降）は自由記入。罫線が無いため `apply_mapping.py` では
  `--allow-outside-border` が要る。

### 『【レコード名】』

- **3ブロック構成**。1ブロック＝1レコードで、1ブロックのデータ行は7行しかない。
  - ブロック1：レコード名7行目／レコードID8行目／見出し9行目／データ10〜16行目
  - ブロック2：18／19／データ20〜26行目
  - ブロック3：28／29／データ30〜36行目
- 入力規則の範囲（`Q10:Q17 Q20:Q27 Q30:Q36` / `R10:R17 R20:R27 R30:R36`）は各ブロックより1行広い。
  **17・27行目は罫線・結合セルが無く、表の外である。** 入力規則だけを見て書くと枠外へはみ出す。
- 39行目の「データ構成サンプル」（A39:X39）と「データ構成イメージ」（Y39:AJ39）は見出し。
  値は40行目以降の枠（A40:X70 / Y40:AJ70）へ書く。

### 背景色の意味

構造メモが列挙する背景色のうち、`#theme0(tint=-0.25)` と `#theme0(tint=0.0)` は
**記入不要を表すグレーアウト**である。白いセルだけが記入対象になる。
