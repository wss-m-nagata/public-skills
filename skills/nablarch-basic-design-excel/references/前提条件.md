# 前提条件・出典

このスキルの記入要領・判断根拠として使っている、プロジェクト固有の事実とその出典をまとめる。
スキル単体で配布・移設した場合に元の裏付けを参照できなくなるため、内容そのものをここに複製して保持する。

## 対象システムのDB種別：PostgreSQL 14.2

`記入要領_テーブル定義書.md`の「データ型」プルダウンの不整合（既定でOracle型名になっている）の判断根拠。

出典：このリポジトリの`sourcecode/compose.yml`

```yaml
services:
  postgres:
    image: postgres:14.2
    ports:
      - "5432:5432"
    environment:
      POSTGRES_PASSWORD: password
    volumes:
      - postgres:/var/lib/postgresql/data
volumes:
  postgres: {}
```

`postgres:14.2`イメージを使用していることから、PostgreSQL 14.2を対象システムのDBと判断している。
プロジェクトのDB構成が変わった場合は、この前提も見直すこと。

## Must4テンプレートの公式配布元

`assets/templates/フォーマット/`・`assets/templates/サンプル/`は、以下のNablarch開発標準の公式リポジトリから取得したもの（`030_設計ドキュメント/010_フォーマット`・`020_サンプル`配下）。

```
https://github.com/nablarch-development-standards/nablarch-development-standards/tree/main/030_設計ドキュメント/010_フォーマット
```

**注意**：このリポジトリのルート`README.md`には上記URLの`master`ブランチ版が記載されているが、`master`ブランチは既に存在せず、デフォルトブランチは`main`である（`master`のリンクは死んでいる）。ルート`README.md`は本スキルの管理対象外のため、そちらは修正していない。

テンプレートの原本が更新された場合は、上記から再取得し、`scripts/extract_structure.py`で構造メモを再生成すること（`plugin_guide.md`の「テンプレートを更新した場合」を参照）。

**注意**：`assets/templates/フォーマット/`配下の表紙シートは、このスキル独自にレイアウトを再設計している（`記入要領_共通シート.md`参照）。公式配布元から再取得した場合、この再設計は失われるため、再取得後は改めて表紙レイアウトの移植が必要になる。
