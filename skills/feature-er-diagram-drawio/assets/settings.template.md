# feature-er-diagram-drawio の設定

このファイルは、`feature-er-diagram-drawio` スキルが読む設定である。  
初回に、プロジェクトから読み取った内容と、質問の回答を保存したもので、以後の実行では、質問せずに、これを使う。  
**規約・設計の手順書の中身は、書かない。** それらの「場所」だけを書く（中身は、実行のたびに、その場所から読む）。  
内容を変えたいときは、「設定を見直したい」と伝えるか、このファイルを直接直す。
