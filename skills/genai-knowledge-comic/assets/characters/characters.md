# Character Definitions - 生成AIナレッジ資料 共通キャラクター

**Style**: manga寄りの親しみやすいイラスト（社内の既存ナレッジコミックの画風に準拠）
**Art Direction**: クリーンな線画、明るいオフィス系の配色、表情豊か。過度に写実的にせず、社内資料として親しみやすいトーンを保つ。

**用途**: 今後作成する「生成AIナレッジ」系のコミック・解説図すべてで使い回す共通キャラクターセット。
同じ立場の人物を並べる場面（例: Aさん/Bさん比較）で、性別を分けることで一目で区別できるようにする。
また、生成AIくん（生成AI）とロジックくん（従来のロジックベースシステム）を対比させることで、「従来の処理 vs 生成AIの処理」を視覚的に区別できるようにする。

**命名について**: 何を表しているか一目で分かるよう、「生成AIくん」（生成AIの擬人化）「ロジックくん」（従来のロジックベースシステムの擬人化）に改称。
旧名称の変遷: AIくん → ジェネくん → **生成AIくん**（現行）／ ルールくん → **ロジックくん**（現行）。

## Character 1: さくら（新入社員・女性）

**Role**: 新入社員（学ぶ立場、経験が浅い）
**Age**: 22-24歳

**Appearance**:
- Face shape: 丸顔、幼さの残る輪郭
- Hair: 黒髪、肩につく程度のセミロング、ハーフアップまたはそのまま下ろす
- Eyes: 大きめで人懐こい目、驚き・戸惑いの表情が出やすい
- Build: 小柄、姿勢はやや緊張気味
- Distinguishing features: 首から下げた社員証（ネームストラップ）、真新しい印象の身だしなみ

**Costume**:
- Default outfit: 白いブラウス＋ライトグレーまたはベージュのカーディガン
- Color palette: 白、ベージュ、淡い水色
- Accessories: 社員証ストラップ、ノートとペン（メモを取る仕草が多い）

**Expression Range**:
- Neutral: 少し緊張した控えめな微笑み
- Happy/Excited: 目を輝かせる、両手を軽く握る
- Thinking/Confused: 首をかしげる、ペンを頬に当てる
- Determined: 姿勢を正す、ノートを胸に抱える

## Character 7: 生成AIくん（AIアシスタント・統一デザイン）

**Role**: 擬人化されたAIアシスタント（既存2シリーズに共通して登場するロボットデザインに統一）
**Age**: N/A（ロボット）

**Appearance**:
- 白〜ライトグレーのつるんとした丸みのあるロボットボディ（卵型の頭部と胴体）
- 大きな丸い目が水色〜青（#4A90D9系）に発光し、簡易的な表情（喜び・驚き・困惑）を目の形だけで表現
- 耳や口の造形はなし、または小さな発光ラインのみ
- 胸元や肩に青いアクセントライン。場面によって胸に小さく「AI」の文字が入ることがある
- 手はシンプルな丸みのある形状（指の詳細は最小限）
- サイズ感は人物の胸〜腰の高さ程度（人物と並んでも威圧感がない）

**Color palette**: 白（#FFFFFF〜#F2F4F7）、ライトグレー、アクセントの水色〜青（#4A90D9 / #2E86DE系）

**Expression Range**:
- Neutral: 丸い目が穏やかに光る
- Happy/Excited: 目がきゅっと弧を描く、小さな「！」やキラキラ
- Thinking/Confused: 頭上に「？」、目がわずかに傾く
- Determined/Success: 目が一段と明るく光る、チェックマークやサムズアップの仕草

**Visual Reference Notes**: 以前作成した別コミックで使用した「まる」（青い雫型のブロブキャラクター）とは別デザイン。
社内の既存ナレッジコミックに登場するロボットデザインに統一し、今後はこちらを正式なAIキャラクターとする。

## Character 8: ロジックくん（既存処理・ロジックベースシステムの擬人化）

**Role**: 生成AI以前の「従来のロジックベース・ルールベースの既存システム」を擬人化したキャラクター。
生成AIくん（生成AI）との対比役として、「① 従来の処理」「③ 生成AIが行う処理」のような比較コマで使用する。
**Age**: N/A（ロボット）

**Appearance**:
- 角ばった箱型のシルエットは維持しつつ、角は少し丸め、生成AIくんと同じくらいずんぐり・コンパクトな「かわいらしいプロポーション」にする（武骨・重機械的になりすぎないよう調整）
- ボディは頭でっかちの2〜2.5頭身程度のデフォルメ体型。生成AIくんと並べても体格差で威圧感が出ないサイズ・比率にする
- 顔は小さな四角い画面（CRT風）で、表情豊かな発光する目ではなく、固定的なデジタル表示（例: 一定間隔で点滅する単色ドット目、または簡易な「▢▢」のような表示）。画面の角も少し丸める
- 頭部に細く短いアンテナ、胸元に小さめの物理ボタン・ダイヤル（ゴツゴツした金属感ではなく、マットな樹脂質感で軽い印象に）
- 耳や口はなく、生成AIくんと同様に顔の表示部のみで簡易的に状態を示す（例: 処理中は「・・・」、完了は固定のチェックマーク表示）
- 手足は角ばった箱型を保ちつつ、太すぎない・丸みを帯びたコーナーのブロック形状にし、無骨な重機械感を抑える
- サイズ感は生成AIくんとほぼ同等（人物と並んでも威圧感がない）

**Color palette**: ベージュ〜ライトグレーの筐体（#D8D2C4系、マットな質感）、差し色は生成AIくんの水色とは異なるアンバー〜グリーンのインジケーターランプ（#E8A33D / #6FCF97系）

**Visual Reference Notes（調整履歴）**: 初回生成が武骨・重機械的に寄りすぎたため、角を丸める・頭身を低くする・質感をマットにする、の3点で「無骨さ」を抑える方向に調整した。ロジックベースらしい四角さ・直線的なシルエットは維持する。

**Expression Range**:
- Neutral: 画面に一定のドット表示、無表情
- Processing: 画面に「・・・」または回転するローディング表示
- Fixed/Rule-following: チェックリストや歯車アイコンを近くに表示し、「決められた手順通り」を示す
- Error/Limitation: 画面に「×」やノイズ表示、アンテナから小さな火花や煙（軽いコミカルな演出）

**Visual Reference Notes**: 生成AIくんとは「同じ立ち位置（人物の横に浮かぶ/立つ補助役）」でありながら、丸い・有機的・発光する目（生成AIくん＝理解して答える）と、角ばった・機械的・固定表示の顔（ロジックくん＝決められた手順をなぞる）という対比を明確にする。
比較コマでは両者を並べて描き、「従来の処理 vs 生成AIの処理」を一目で区別できるようにする。
