# DADS 値の早見表（手で確かめた部分）

トークンから作れる値（色、文字、角丸、影）は、`quick-values-tokens.md`（`scripts/gen_quick_values.py` で生成）を参照する。
このファイルは、トークンにない値を、**ローカルの原文から確かめて書いたもの**である。
**元の資料が正**であり、迷ったときは出典の原文を読む。原文を更新したら、このファイルの値も確かめ直す。

確認日: 2026-10-04（ローカルの原文の取得日は `VERSION.txt` を参照）

## 文字（`foundations/typography/index.md`）

| 項目 | 値 |
| --- | --- |
| 文字の太さ | 400（N）と700（B）の2段階 |
| 文字の大きさの基準 | 本文とUIは16px以上。14pxは領域に制約があるときだけ。14px未満は原則として許容されない |
| 行の高さ（CSSは単位なしの数値） | 100%（1行のテキスト）、120%・130%（管理画面や業務システムで表示する情報量を優先）、140%（見出し）、150%（一般的な本文と見出し）、160%・170%・175%（一般的な本文） |
| テキストスタイルの種類 | Display（Dsp）、Standard（Std）、Dense（Dns）、Oneline（Oln）、Mono |
| スタイル名の形 | 「種類-大きさ + 太さ - 行の高さ」（例: `Std-16N-170` は 16px／400／170%） |
| Dense の位置づけ | 管理画面や業務システムなど、限られた領域での表示する情報量を優先する。データテーブルなど |
| 字間（letter-spacing） | Display・Dense・Monoは0。Onelineは2%。Stdは、45pxが0、28〜36pxが1%、16〜26pxが2% |

| スタイル | 正方形 | 長方形 |
| --- | ---: | ---: |
| 角丸なし | 0 | 0 |

| 角丸ミディアム | 16 | 12 |

## 余白（`foundations/spacing/index.md`）

- 基準単位は8px。
- 余白スケールは3〜5段階が多い。適用例は 8px（等倍）、24px（3倍）、64px（8倍）。
- 確定した値の一覧はない。

## 色の要件（`foundations/color/index.md`）

| 用途 | 要件 |
| --- | --- |
| テキスト | 背景に対して4.5:1以上。大きい文字の例外は設けない |
| ボーダー・区切り線・アイコンなど、テキスト以外 | 隣接する背景に対して3:1以上 |
| グレーの境目（白の背景に対して） | Gray-420は3:1、Gray-536は4.5:1 |
| フォーカスの表示 | Yellow-300と黒の2重の構造。変えてはいけない。線の太さは定められていない |
| 色だけで区別しない | 状態や意味を、色だけで伝えない |

色の組み合わせは `scripts/contrast.py` で確かめる。

## ボタン（`components/button/index.md`）

| サイズ | 最小の幅 × 高さ |
| --- | --- |
| Large | 136 × 56 |
| Medium | 96 × 48 |
| Small | 80 × 36 |
| X-Small | 72 × 28 |

| 種類 | 重要度 | 使う数 |
| --- | --- | --- |
| 塗り | 高 | 1画面に原則1つ |
| アウトライン | 中 | 文脈ごとに原則3つまで |
| テキスト | 低（キャンセルなど） | 原則1つ |

- 押せる範囲は44px以上。ボタン以外のリンクは24×24px以上。
- ボタンどうしの間隔の作例は8px。
- 配置（デスクトップ）: 進める操作は右寄せで、塗りボタンを右端に置く。キャンセルや戻るは左寄せ。ボタンが1つだけなら右端（モーダルでは中央）。
