# 原則と規約の対応（目安）

画面設計の基本原則を守るために、規約で決めておく必要があること（左）と、規約テンプレート（`assets/screen-design-rules-template/`）のどのファイル・章で扱うか（中）の目安。
導入手順の「4. 規約との対応を確認する」で使う。

- 「目安」である。規約の実際の内容は、出力先の規約を読んで確認する。
- 規約テンプレートに該当する章がないものは、「章なし」と書いた。独自ルールに書く、別の資料で定義するなどを、ユーザーに確認する。

| 規約で決めておくこと | 規約テンプレートでの扱い | 根拠になる原則 |
|---|---|---|
| 画面の基本構成（ヘッダー、メニュー、タイトル、検索条件、一覧、ボタン領域の配置） | `layout.md` 2. アプリケーション全体の構成、5. Main Content | 5-1、1-2、1-4、2-4、5-3 |
| 画面種別ごとのレイアウト（検索一覧、詳細、登録・編集、確認、完了） | `page-patterns.md` | 5-1、1-2 |

## 規約テンプレートに章がない項目（改善案として提示する）

導入時に、次の項目は、規約テンプレートに該当する章がない。
ユーザーに、「プロジェクト独自ルールに書く」「別の資料で定義する」「対象外にする」のいずれかを確認する。
規約テンプレートの構造は、独自判断で変更しない。

- 用語・メッセージの書き方
- 処理中・進捗の表示
- ショートカットキー
- 機密情報の表示、公開範囲
- 時間制限
