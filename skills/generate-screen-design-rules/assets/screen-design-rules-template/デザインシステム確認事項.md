# デザインシステム確認事項

`generate-screen-design-rules` Skillが画面設計規約（`foundations.md` `layout.md` `navigation.md` `components.md` `page-patterns.md` `accessibility.md`）を生成・更新するたびに、各ファイルの `暫定` / `要確認` 項目をこの一覧へ書き出します（手作業では更新しません）。

- **要確認**: まだ値そのものが無く、プロジェクト側の判断が無いと決められない項目です。先にご確認ください。
- **暫定**: DADS / Carbon等をもとに一旦値を入れていますが、採用するか変更するかの確認待ちです。

`要確認` を先に、`暫定` を後に並べます。この一覧が空になれば、規約に確認待ちの項目が無い状態です。

状態の意味は [README.md](./README.md) の「状態の見方」を参照してください。
