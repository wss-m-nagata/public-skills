# デザインシステム管理台帳

画面設計規約を生成・更新するときに、各項目の状態、確認事項、出典と参照先を確認するための資料です。
規約ファイルの見出しや表の項目に対応づけて管理します。

## 状態の見方

- **要確認**: プロジェクトの判断が必要で、値や適用条件が決まっていない項目です。
- **暫定**: 候補はありますが、採用するか確認が必要な項目です。
- **確定**: プロジェクトの規約として決まった項目です。

確認が必要な項目は、要確認、暫定の順に記載します。
確定済みの項目も出典とともに保持します。
プロジェクトに未決事項の管理先の指定がある場合は、確認内容をその管理先に記載し、台帳から参照します。

## 項目一覧

| 規約ファイル・見出し・項目 | 状態 | 候補値・確認内容または管理先 | 出典・採用範囲 | 参照ヒント・URL・ローカル参照 |
|---|---|---|---|---|

テンプレートの状態、出典、参照先、確認事項を、生成時にこの一覧へ移します。
一つの節に異なる状態の項目がある場合は項目ごとに行を分けます。
ローカル参照はスキルに同梱された資料へのパスです。
