# 設計原則適用方針

画面設計の基本原則（第1.1版）を、このプロジェクトでどう適用するかをまとめる。

- 表示番号・原則名は、画面設計の基本原則のとおりに書く。変更しない。
- 「適用」は、`必須` / `推奨` / `対象外` のいずれか。`対象外` には理由を書く。法令・適用基準等の要求事項は、対象外にしない。
- 「状態」は、画面設計規約と同じ、`確定` / `暫定` / `要確認` を使う。
- 「規約での担保先」には、その原則を担保する規約のファイル・章を書く。担保できていない場合は `なし` と書き、状態を `要確認` にする。
- 数値の例（画面幅、倍率、コントラスト比、制限時間など）は、このプロジェクトで定めた値を書く。
